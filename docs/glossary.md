GIS Glossary
GIS
Geographic Information System.
A system for managing, analyzing, and communicating information associated with geographic location.
CRS
Coordinate Reference System.
Defines how geographic coordinates correspond to real locations on Earth.
Geographic CRS
Represents locations using angular coordinates, commonly latitude and longitude.
Projected CRS
Represents locations on a planar coordinate system, frequently using meters or feet.
Vector
Spatial model representing discrete objects through points, lines, and polygons.
Raster
Spatial model represented as a grid of cells.
Spatial Join
Operation that transfers or aggregates attributes based on geographic relationships.
Buffer
Area created around a spatial feature at a specified distance.
Intersect
Operation identifying the spatial overlap between datasets.
GeoPackage
Open OGC spatial format based on SQLite.
File Geodatabase
Esri spatial data storage format.
PostGIS
Spatial extension for PostgreSQL.
GDAL
Open-source geospatial data access and transformation library.
PROJ
Coordinate transformation and projection library.
GEOS
Geometry-processing engine used by many open-source GIS tools.
ArcPy
Python package for ArcGIS geoprocessing and automation.
PyQGIS
Python API for QGIS.
GeoPandas
Python library extending pandas with geospatial data structures and operations.
